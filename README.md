```md id="readme1"


This project is an educational cybersecurity lab created to understand how credential phishing attacks work and how security professionals detect and defend against them.

The lab demonstrates fake login page behavior, phishing indicators, and social engineering concepts in a controlled environment for cybersecurity awareness and defensive learning purposes only.



Features
  Phishing awareness simulation
  Fake login page demonstration
  Credential phishing analysis
  Social engineering study
  Security awareness training
  Defensive cybersecurity learning


Technologies Used
 Linux
 Bash
 Git & GitHub
 Networking Basics
 Cybersecurity Concepts

---

  Learning Objectives
This project helped me learn:
 How phishing attacks target users
 How fake login pages are created
 Common credential theft techniques
 Social engineering tactics
 Cybersecurity awareness practices
 Defensive security concepts




 Disclaimer
This project is created strictly for educational and cybersecurity awareness purposes only.

The project is intended for use in controlled lab environments to study phishing techniques, credential theft risks, and defensive security practices.
```
